# MI Senate — what's on the air

A daily snapshot of television advertising in the 2026 Michigan U.S. Senate race:
every ad detected on broadcast or CTV, the money behind each one, and the markets
it is running in.

`index.html` is generated each morning and carries every day published so far — use
the date picker at the top to move between them. Tapping a legend key filters the
chart to those ads and rescales it.

**Source:** AdMo+ per-creative analysis. Broadcast and CTV are separate, disjoint
buckets and are reported separately; digital dollars are not mixed in. CTV reports
roughly a day behind broadcast, so the most recent CTV figures run slightly light.

This repository contains only the generated report. It holds no campaign data files,
no ingest code, and no internal notes.
